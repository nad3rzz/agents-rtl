# Agents RTL

✨ RTL and chat controls for Codex and Gemini Code Assist in VS Code and Antigravity.

## ✨ Features

- ↔️ Arabic RTL formatting, including selected text and comments.
- 🧵 Codex chat tabs, rename, and archive.
- 🔔 Reply and approval indicators.
- ↕️ Optional scroll controls.

## 🔗 Links

- 🧩 [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Nad3r.agents-rtl)
- 🌐 [Open VSX](https://open-vsx.org/extension/nad3r/agents-rtl)

Supports 🐧 Linux x64 and 🪟 Windows x64.

First install needs one editor restart. Setup is automatic after that.
