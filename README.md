# Agents RTL

Plug-and-play Arabic RTL support, chat tabs, and scroll controls for Codex and AI agent webviews in VS Code-compatible editors, including VS Code and Antigravity.

- VS Code Marketplace: https://marketplace.visualstudio.com/items?itemName=Nad3r.agents-rtl
- Open VSX Registry: https://open-vsx.org/extension/nad3r/agents-rtl

Supports Linux and Windows x64.

## Features

- Arabic RTL formatting for Codex and agent chat messages.
- RTL-aware composer text in VS Code and Codex webviews.
- Codex chat tabs for quickly switching between active workspace conversations.
- Optional up/down scroll controls for long chats.
- Supports VS Code and Antigravity-compatible editor webviews.
